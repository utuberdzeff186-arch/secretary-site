Политика конфиденциальности

Дата последнего обновления: 2026 год.

Настоящая Политика конфиденциальности действует в соответствии с Федеральным законом от 27.07.2006 № 152-ФЗ «О персональных данных» и определяет порядок обработки персональных данных пользователей сайта «Секретарь».

1. Оператор персональных данных

Оператором персональных данных является независимый разработчик проекта «Секретарь». Связаться с оператором можно через GitHub.

2. Сбор данных

Программа «Секретарь» (SecretarySetup.exe) работает полностью локально. Мы не собираем, не храним и не передаем третьим лицам ваши личные файлы, пароли или историю посещений.

На сайте мы можем собирать следующие технические данные (с вашего согласия через Cookie):

  • Адрес электронной почты (если вы добровольно подписались на новости о релизе).
  • Анонимные технические данные (IP-адрес для работы встроенных инструментов проверки).

3. Файлы Cookie

Мы используем технические Cookie для сохранения ваших настроек и предотвращения повторного показа уведомлений. Продолжая использовать сайт, вы соглашаетесь с этим.

4. Сторонние сервисы

Сайт использует открытые API (HaveIBeenPwned, ipapi.co) для работы встроенных кибер-инструментов. Все запросы к этим API анонимизированы (k-anonymity) и не позволяют идентифицировать вас.
