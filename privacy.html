Политика конфиденциальности

Дата последнего обновления: 2026 год.

Мы ценим вашу конфиденциальность и считаем, что антивирус не должен следить за пользователем. Эта страница объясняет, как программа «Секретарь» и наш сайт обращаются с вашими данными.

1. Сбор данных программой

Программа «Секретарь» (SecretarySetup.exe) работает полностью локально на вашем компьютере.

  • Мы не собираем ваши личные файлы, пароли или историю посещений.
  • Мы не отправляем никакие данные на наши серверы.
  • Программа не требует подключения к интернету для базовой работы.

2. Сбор данных сайтом

Наш сайт размещен на платформе GitHub Pages. Мы не используем сторонние трекеры, рекламные скрипты или системы аналитики (например, Google Analytics).

Встроенный чат-бот на сайте работает исключительно в вашем браузере (на JavaScript). Ваши сообщения не передаются на сервер и нигде не сохраняются.

3. Файлы Cookie

Мы не используем файлы cookie для отслеживания ваших действий. GitHub может использовать технические cookie для обеспечения работы самого хостинга.

4. Сторонние ссылки

Наш сайт содержит ссылки на GitHub и скачивание файла. Мы не несем ответственности за политику конфиденциальности сторонних ресурсов.

5. Контакты

Если у вас есть вопросы по поводу этой политики, вы можете связаться с разработчиком через GitHub.
