Политика конфиденциальности

Дата последнего обновления: 2026 год.

Настоящая Политика конфиденциальности действует в соответствии с Федеральным законом от 27.07.2006 № 152-ФЗ «О персональных данных» и определяет порядок обработки персональных данных пользователей сайта «Секретарь».

1. Оператор персональных данных

Оператором персональных данных является независимый разработчик проекта «Секретарь». Связаться с оператором можно через GitHub.

2. Сбор данных

Программа «Секретарь» (SecretarySetup.exe) работает полностью локально. Мы не собираем, не храним и не передаем третьим лицам ваши личные файлы, пароли или историю посещений.

На сайте мы можем собирать следующие данные (только с вашего явного согласия):

  • Адрес электронной почты — если вы добровольно подписались на новости о релизе через форму на главной странице. Внимание: в текущей версии сайта email сохраняется только в вашем браузере (localStorage) и никуда не отправляется.
  • IP-адрес — при использовании встроенных кибер-инструментов (проверка IP, проверка утечек) запросы идут напрямую в открытые API и не сохраняются на серверах сайта.
  • Технические данные (Cookie) — для обеспечения работы сайта.

3. Файлы Cookie

Мы используем технические Cookie для сохранения ваших настроек (например, чтобы не показывать баннер согласия повторно). Продолжая использовать сайт, вы соглашаетесь с этим.

4. Сторонние сервисы

Сайт использует открытые API (HaveIBeenPwned, ipapi.co, api.qrserver.com) для работы встроенных кибер-инструментов. Все запросы к этим API анонимизированы и не позволяют идентифицировать вас как конкретную личность.

5. Ваши права

Вы имеете право:

  • Отозвать согласие на обработку персональных данных в любой момент.
  • Потребовать удаления ваших данных (например, удалив их из localStorage вашего браузера).

6. Контакты

Если у вас есть вопросы по поводу этой политики, вы можете связаться с разработчиком через GitHub.
